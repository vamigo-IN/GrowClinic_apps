# GrowClinic.io - India's Elite Health-Tech Agency

GrowClinic is a premium patient acquisition system engineered for elite doctors and clinics. We automate growth through intelligent automation, high-converting patient systems, and data-driven marketing.

## 🚀 Key Features

- **Automated Patient Acquisition**: Custom-built machines to scale practice revenue.
- **Sync WhatsApp Automation**: Next-gen WhatsApp engine for bookings, prescriptions, and billing.
- **Clinic Growth Audit**: Data-backed audit system for practice analysis.
- **Elite Performance Dashboard**: Real-time tracking of leads, bookings, and ROI.
- **Professional Project Showcase**: Case studies of successful medical growth transformations.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com)
- **Database**: [Prisma](https://www.prisma.io) with PostgreSQL
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev)

## 📦 Getting Started

### Prerequisites

- Node.js 20+
- PostgreSQL database

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/growclinic-app.git
   cd growclinic-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory:
   ```env
   DATABASE_URL="your-postgresql-url"
   NEXTAUTH_SECRET="your-secret"
   ```

4. **Initialize Database:**
   ```bash
   npx prisma generate
   npx prisma db push
   ```

5. **Run Development Server:**
   ```bash
   npm run dev
   ```

Visit [http://localhost:3000](http://localhost:3000) to see the result.
